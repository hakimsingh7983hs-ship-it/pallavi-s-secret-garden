# Pallavi's Secret Garden

Create a premium interactive romantic surprise website for my fiancée, Pallavi.

IMPORTANT:

This should NOT look like a normal website, portfolio, landing page, or simple photo gallery.

I want it to feel like an interactive animated romantic experience / mini game where my fiancée discovers surprises one by one.

The inspiration is the attached reference screenshots: soft pastel backgrounds, hand-drawn animations, flowers, hearts, romantic typography, interactive puzzles, photo memories, an animated door/museum, a handwritten love letter and a final surprise.

Do NOT simply copy the reference. Create an original experience with the same emotional concept and interaction quality.

==================================================

CORE EXPERIENCE

==================================================

The website should have approximately 7–9 interactive rooms/scenes.

The user should NOT be able to simply scroll through everything.

Each scene should require a small interaction before the next scene unlocks.

Examples:

- Click a button

- Tap hearts

- Grow a tree

- Arrange photos

- Solve a simple puzzle

- Knock on a door 3 times

- Open an envelope

- Click a hidden object

- Enter the final room

Every transition should feel magical and surprising.

Use smooth animations between scenes.

Mobile-first design is extremely important because Pallavi will open this on her phone.

"I made something for you..."

Then display:

"Are you ready?"

"Look what you helped me grow. ❤️"

"Our little world."

SURPRISE / ANIMATION DETAILS

==================================================

Make the animations a major part of the experience.

Use:

- GSAP or Framer Motion

- Smooth fade transitions

- Typewriter text

- Floating hearts

- Falling rose petals

- Hand-drawn SVG animations

- Particle effects

- Soft glowing lights

- Polaroid photo animations

- 3D door opening

- Envelope opening

- Puzzle interaction

- Confetti/heart burst

- Parallax movement

- Hover/touch interactions

- Subtle sound effects

- Optional romantic background music

Do NOT overuse animations.

Everything should feel elegant, emotional and cinematic.

MOBILE EXPERIENCE

==================================================

This is extremely important.

The website will primarily be opened on an iPhone.

Design for 390px–430px width first.

Every interaction must work with touch.

No tiny buttons.

No horizontal scrolling.

Use full-screen scenes.

Animations must remain smooth on mobile.

FINAL REQUIREMENT

The website should feel like a journey.

Pallavi should constantly wonder:

Make it feel like Hakim secretly built a magical little world specifically for Pallavi. ❤️
